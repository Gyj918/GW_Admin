## 一、Vue 3 概述

Vue 3 是渐进式 JavaScript 框架 Vue.js 的重大版本更新，于 2020 年 9 月正式发布。它保留了 Vue 2 的核心思想，同时在性能、可维护性和开发体验方面做出了显著改进。

### 核心优势
- **更好的性能**：重写的虚拟 DOM，更快的渲染速度
- **更小的体积**：Tree-shaking 支持，核心仅 10KB gzipped
- **组合式 API**：更好的逻辑复用和代码组织
- **更好的 TypeScript 支持**：代码库完全用 TypeScript 重写
- **新的响应式系统**：基于 Proxy 的响应式实现

## 二、核心架构与响应式系统

### 1. 响应式系统重写

Vue 3 使用 Proxy 替代了 Vue 2 的 `Object.defineProperty`：

```javascript
import { reactive, effect } from 'vue'

const state = reactive({
  count: 0
})

// 自动追踪依赖
effect(() => {
  console.log('count is:', state.count)
})

state.count++ // 触发 effect 重新执行
```

### 2. 虚拟 DOM 优化

- **静态树提升**：标记静态节点，跳过比对
- **静态属性提升**：缓存静态属性
- **Patch Flag**：动态节点标记，仅比对动态部分
- **Fragment 支持**：无需根节点包裹

## 三、组合式 API (Composition API)

### 1. 基本使用

```vue
<script setup>
import { ref, computed, onMounted } from 'vue'

// 响应式状态
const count = ref(0)

// 计算属性
const doubleCount = computed(() => count.value * 2)

// 方法
function increment() {
  count.value++
}

// 生命周期
onMounted(() => {
  console.log('组件已挂载')
})
</script>

<template>
  <button @click="increment">
    Count is: {{ count }}, Double is: {{ doubleCount }}
  </button>
</template>
```

### 2. 逻辑复用

**useCounter.js**
```javascript
import { ref, computed } from 'vue'

export function useCounter(initialValue = 0) {
  const count = ref(initialValue)
  
  const doubleCount = computed(() => count.value * 2)
  
  function increment() {
    count.value++
  }
  
  return {
    count,
    doubleCount,
    increment
  }
}
```

**组件中使用**
```vue
<script setup>
import { useCounter } from './useCounter'

const { count, doubleCount, increment } = useCounter(10)
</script>
```

## 四、Teleport、Suspense 等新特性

### 1. Teleport

将子节点渲染到 DOM 中的其他位置：

```vue
<template>
  <button @click="modalOpen = true">打开模态框</button>
  
  <Teleport to="body">
    <div v-if="modalOpen" class="modal">
      <p>这是一个模态框</p>
      <button @click="modalOpen = false">关闭</button>
    </div>
  </Teleport>
</template>
```

### 2. Suspense

处理异步组件加载状态：

```vue
<template>
  <Suspense>
    <template #default>
      <AsyncComponent />
    </template>
    <template #fallback>
      <div>加载中...</div>
    </template>
  </Suspense>
</template>

<script setup>
const AsyncComponent = defineAsyncComponent(() =>
  import('./AsyncComponent.vue')
)
</script>
```

## 六、状态管理

### 1. 使用 Pinia (推荐)

```javascript
// stores/counter.js
import { defineStore } from 'pinia'

export const useCounterStore = defineStore('counter', {
  state: () => ({
    count: 0
  }),
  getters: {
    doubleCount: (state) => state.count * 2
  },
  actions: {
    increment() {
      this.count++
    }
  }
})
```

### 2. 在组件中使用

```vue
<script setup>
import { useCounterStore } from '@/stores/counter'

const counter = useCounterStore()
</script>

<template>
  <div>{{ counter.count }}</div>
  <button @click="counter.increment()">+</button>
</template>
```

## 七、路由与导航

### 1. Vue Router 4

```javascript
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  {
    path: '/',
    component: Home,
    meta: { requiresAuth: true }
  },
  {
    path: '/about',
    component: () => import('./views/About.vue') // 懒加载
  }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})
```

### 2. 路由守卫

```javascript
router.beforeEach((to, from) => {
  if (to.meta.requiresAuth && !isAuthenticated) {
    return { path: '/login' }
  }
})
```

### 3. 组合式 API 中使用路由

```vue

const route = useRoute()
const router = useRouter()

  router.push('/about')
}
</script>
```

## 十、测试策略

### 1. 单元测试 (Vitest)

```javascript
import { render } from '@testing-library/vue'
import Counter from './Counter.vue'

test('increments value on click', async () => {
  const { getByText } = render(Counter)
  
  getByText('Count is: 0')
  
  const button = getByText('Increment')
  await button.click()
  
  getByText('Count is: 1')
})
```

### 2. 组件测试

```javascript

})
```

## 十二、最佳实践

### 1. 项目结构

```
src/
├── assets/          # 静态资源
├── components/      # 公共组件
│   ├── base/        # 基础UI组件
│   └── features/    # 功能组件
├── composables/     # 组合式函数
├── stores/          # Pinia状态
├── router/          # 路由配置
├── views/           # 路由组件
├── utils/           # 工具函数
├── App.vue          # 根组件
└── main.ts          # 应用入口
```

### 2. 代码组织

```vue
<script setup>
// 1. 导入
import { ref, onMounted } from 'vue'
import { useRouter } from 'vue-router'

// 2. 组合式函数
const { data, fetchData } = useFetchData()

// 3. 本地状态
const count = ref(0)

// 4. 计算属性
const doubleCount = computed(() => count.value * 2)

// 5. 方法
function increment() {
  count.value++
}

// 6. 生命周期
onMounted(fetchData)
</script>
```

### 3. 性能优化技巧
- 使用 `v-once` 标记静态内容
- 合理使用 `v-memo` 优化大列表
- 避免在模板中使用复杂表达式
- 按需引入组件库
- 使用 `shallowRef` 和 `shallowReactive` 减少响应式开销
