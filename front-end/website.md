# 公司官网项目

### **一. 项目名称**
`公司官网项目`
### **二、项目时间**
`2024年-12月 - 2025年1月`
### **三、项目角色**
 `Web前端工程师 `

### **四、项目简介**

本项目是为公司打造的全新官方网站，旨在提升品牌形象、展示公司实力、并吸引潜在客户。作为项目的全栈开发者与UI设计师，我独立完成了从需求分析、界面设计、前后端开发到部署上线的整个流程。

### **五、技术栈与工具**

* **全栈框架:** Next.js (前端 + 后端)
* **编程语言:** TypeScript
* **样式:** Tailwind CSS
* **数据库:** Lowdb (轻量级数据库)
* **部署:** Node.js 环境部署

### **六、关键职责**

* **一体化全栈开发:**  利用Next.js集成的API路由功能，实现前后端代码同仓库、同框架开发，简化开发流程，提升开发效率。
* **高性能与SEO优化:**  采用Next.js的服务端渲染 (SSR) 和静态生成 (SSG) 功能，提升页面加载速度和搜索引擎排名，助力公司官网在竞争中脱颖而出。
* **响应式设计:**  使用Tailwind CSS构建响应式布局，确保网站在各种设备上都能完美呈现，为用户提供流畅的浏览体验。
* **交互体验优化:**  运用React构建动态交互组件，例如轮播图、下拉菜单、表单验证等，提升用户操作体验，增强用户粘性。
* **内容管理系统 (CMS):**  集成自定义CMS，方便公司人员更新网站内容，例如新闻动态、产品信息等，实现网站内容的自主管理。
* **独立UI设计:**  从零开始设计网站UI，包括色彩搭配、字体选择、图标设计、页面布局等，打造符合公司品牌形象的视觉风格，提升品牌辨识度。

### **七、项目成果**

* 成功上线官方网站，获得公司领导和客户的一致好评。
* 网站访问量和用户停留时间显著提升，有效促进了公司业务发展。
* 独立完成全栈开发和UI设计，充分展现了个人技术能力和创造力。
