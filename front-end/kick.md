# 踢球吧
---

### **一. 项目名称**
`踢球吧`
### **二、项目时间**
`2023年1月 - 2023年4月`
### **三、项目角色**
 `Web前端工程师 `
### **四、项目简介**
足球比赛预约小程序兼后台管理系统，主要有报名比赛、球员分组、场地管理、支付管理、退款管理、
赛事记录管理等功能模块。

### **五、技术栈与工具**
- 编程语言：`JavaScript、Java`
- 框架与库：`Vue3、VueRouter、Pinia、ElementPlus、uni-app、uView`
- 开发工具：`Visual Studio Code, IDEA`
- 部署：`云服务`

### **六、关键职责与成就**

- **职责**：采用 uni-app、uView 进行小程序客户端的开发，实现产品级 UI 还原。
- **职责**：基于 springboot 进行后台 API 的开发。
- **职责**：通过 Vue 和 ElementUI 进行后台管理端的开发。
- **职责**：将小程序与微信支付系统对接，实现顺畅的下单与付款流程。
