**项目简介**

本项目是一个基于 Node.js 的商城后台管理系统，采用前后端分离架构，提供了一套完整的电商后台管理功能，包括商品管理、订单管理、用户管理、数据统计等模块。项目代码简洁清晰，易于理解和二次开发，适合用于学习和构建中小型电商平台。

### **技术栈**

* **后端:** 
    * **Node.js:**  轻量高效的 JavaScript 运行时环境，适合构建高性能的网络应用。
    * **Express.js:**  基于 Node.js 的 Web 应用框架，提供简洁灵活的 API，方便快速构建 Web 应用。
    * **Mysql:**  基于关系型数据库，具有高性能、高可用性和易扩展性等特点。
    * **Mongoose:**  MongoDB 的对象模型工具，提供 schema 定义、数据验证、中间件等功能，简化 MongoDB 操作。
    * **JWT (JSON Web Token):**  一种开放标准 (RFC 7519)，用于在各方之间安全地传输信息，常用于用户身份验证和授权。
* **前端:** 
    * **Vue.js (可选用其他前端框架):**  渐进式 JavaScript 框架，易于上手，功能强大，适合构建用户界面。
    * **Element UI (可选用其他 UI 库):**  基于 Vue.js 的桌面端组件库，提供丰富的 UI 组件，方便快速构建美观的界面。
* **其他:**
    * **RESTful API:**  一种软件架构风格，定义了一组约束条件和原则，用于创建 Web 服务。
    * **Git 版本控制:**  分布式版本控制系统，用于跟踪代码更改，方便团队协作和代码管理。

### **功能模块**

* **商品管理:** 
    * **商品分类管理:**  支持多级商品分类，方便商品归类和管理。
    * **商品信息管理:**  提供商品信息的增删改查功能，包括商品名称、价格、描述、图片等。
    * **商品图片上传:**  支持商品图片上传，并支持图片预览和裁剪功能。
    * **商品库存管理:**  实时监控商品库存，支持库存预警和库存调整功能。
* **订单管理:**
    * **订单列表查询:**  支持按时间、状态、用户等条件查询订单信息。
    * **订单状态管理:**  支持订单状态的修改，例如待付款、待发货、已发货、已完成等。
    * **订单发货管理:**  支持订单发货操作，并生成发货单。
* **用户管理:**
    * **用户信息管理:**  支持用户信息的增删改查功能，包括用户名、密码、邮箱、手机号等。
    * **用户权限管理:**  支持用户角色的定义和权限分配，实现不同用户角色的权限控制。
* **数据统计:**
    * **销售数据统计:**  提供商品销售数据的统计和分析，例如销售额、销售量、订单数量等。
    * **用户行为分析:**  分析用户行为数据，例如用户访问量、用户活跃度、用户留存率等。
