# Creat-gw-app：基于 Vite 的 React 项目脚手架工具 <Badge type="tip" text="开源" />

### **项目简介**

Creat-gw-app 是一个基于 **Vite** 构建的 React 项目脚手架工具，公司内部项目开发而设计。它的目标是提升团队开发效率、统一项目规范，并减少重复性工作。通过集成现代化的工具链和最佳实践，creat-gw-app 帮助开发者快速启动高质量、可维护的 React 项目，同时确保团队协作的一致性。

### **开发背景**

在日常内部项目开发过程中，我注意到团队在初始化新项目时，常常面临以下问题：
1. **重复配置：** 每个新项目都需要重新配置构建工具、代码规范、样式处理等，浪费大量时间。
2. **规范不统一：** 不同项目之间的目录结构、代码风格、工具版本等存在差异，增加了维护成本。
3. **开发效率低：** 缺乏统一的工具链支持，开发者在环境搭建和配置上花费过多精力。

为了解决这些问题，开发了 **creat-gw-app**，将团队内部的最佳实践和工具链整合到一个脚手架工具中，让开发者能够专注于业务逻辑，而不是繁琐的配置。

### **项目特点**

* **基于 Vite 构建：** 利用 Vite 的高性能开发服务器和快速构建能力，提供极致的开发体验。
* **开箱即用的配置：** 集成公司内部常用的工具链，包括 ESLint、Prettier、Husky、Commitlint 等，确保代码质量和提交规范。
* **统一的项目规范：** 提供标准的目录结构、代码风格和开发流程，减少团队协作中的摩擦。
* **高度可定制化：** 支持通过命令行选项或配置文件灵活调整项目模板，满足不同项目的需求。
* **开发效率提升：** 内置常用工具和脚本，例如组件生成器、路由配置工具等，减少重复性工作。

### **技术栈**

* **核心框架:** React
* **构建工具:** Vite
* **代码格式化:** Prettier
* **代码检查:** ESLint
* **提交规范:** Commitlint
* **样式处理:** CSS/SCSS/Less (可选)
* **路由:** React Router (可选)
* **状态管理:** Redux/Zustand (可选)
* **TypeScript 支持:** 可选

### **功能亮点**

1. **统一的项目模板：**
   - 提供标准的目录结构，例如 `src/components`、`src/pages`、`src/utils` 等。
   - 内置公司内部的代码规范和 ESLint 配置，确保代码风格一致。

2. **高效的开发体验：**
   - 基于 Vite 的快速启动和热更新，提升开发效率。
   - 集成 Prettier 和 ESLint，自动格式化代码并检查错误。

3. **规范的 Git 工作流：**
   - 集成 Husky 和 Commitlint，强制规范 Git 提交信息。
   - 提供预提交检查，确保代码质量和规范。

4. **灵活的配置选项：**
   - 支持通过命令行选项选择是否集成 TypeScript、状态管理工具、UI 组件库等。
   - 提供配置文件，允许开发者根据项目需求调整工具链。

5. **内置工具支持：**
   - 提供组件生成器，快速创建标准化的 React 组件。
   - 集成路由配置工具，简化路由管理。

**使用指南**

1. 安装 Node.js 环境。
2. 使用 npm 或 yarn 全局安装 creat-gw-app：
   ```bash
   npm install -g creat-gw-app
   # 或
   yarn global add creat-gw-app
   ```
3. 使用 creat-gw-app 命令生成项目：
   ```bash
   creat-gw-app my-react-app
   ```
4. 根据命令行提示选择项目配置（例如是否支持 TypeScript、是否集成 Redux 等）。
5. 进入项目目录并安装依赖：
   ```bash
   cd my-react-app
   npm install
   # 或
   yarn install
   ```
6. 启动开发服务器：
   ```bash
   npm run dev
   # 或
   yarn dev
   ```
